# Retro — offerings module, MyDrHank run (2026-06-03)

An early `offerings.md` run, **second use of the 9-column shape** and the **first on a custom React/Vite SPA**
(prior runs: Hone custom-ish, AgelessRx WordPress, Eden Webflow). Artifact landed clean —
[`store/mydrhank-com/offerings.md`](../../../store/mydrhank-com/offerings.md): 16 buyable + 5 family rows, 22
credits, lint-pass. Generalizable learnings, each tagged by where it lands + now/later.

## New ground — the custom-SPA platform branch

**1. For a custom SPA, the JS bundle *is* the catalog oracle — beating nav + census.** `[recipe]` · *later*
Triggered by: a sparse `/map` (12 URLs) and a nav that showed 15 SKUs. The authoritative list was the
hard-coded `Ep=[{slug,name,category}]` registry + React-Router route table inside `assets/index-*.js`. It
revealed a **16th SKU the nav filters out in code** (`/products/hair-combo`, live PDP, `Ep.filter(s!=="hair-combo")`).
This **extends Eden #1** (branch the ladder on `design_framework`) with a *third* branch — WordPress/Shopify →
REST; Webflow → nav+census; **custom SPA → mine the bundle registry.**

**2. Blind-source agreement can be doubly blind.** `[recipe]`/`[contract]` · *later* · **contradicts Eden #1.**
Eden's lesson: nav == census "licenses complete." Here it would have *lied* — the nav code-filtered `hair-combo`
**and** the sparse census missed it; only the bundle registry caught it. When the catalog is code-gated, nav and
census are the same blind source. **Refinement:** on a custom SPA, the registry is the completeness backbone, and
nav/census agreement is *not* sufficient evidence of completeness.

**3. The soft-200 trap — a 200 is not a backend.** `[recipe]` · *now (prompt)* + *later (recipe)* · **refines
AgelessRx #1.** `/wp-json/wp/v2/types` returned **HTTP 200** — looked like WordPress. It was the SPA's
`index.html` catch-all (200 for every unmatched path). The CMS-REST rung needs a guard: **verify the body is JSON,
not the SPA shell**, before trusting a REST registry. `/products.json` and `/sitemap.xml` 404'd (the *honest*
answers); the 200 was the deceptive one.

**4. The bundle is a reliable *catalog* oracle but an unreliable *price* oracle.** `[recipe]` · *validate*
The bundle held **conflicting prices** for one slug (`compounded-tirzepatide`: `price:200` *and* `price:240`); only
the rendered PDP/homepage disambiguates the live one ($240). **Mine the bundle for slugs/names/categories; capture
the rendered page for verbatim price.** This vindicates "scrape the page, don't trust the bundle blindly."

## Cross-brand confirms

**5. Price-on-PDP-only → cost scales with SKU count.** `[recipe]` · *validate* · **confirms AgelessRx #2.**
Only the weight-loss category page showed prices; the other three hid them. A complete verbatim-priced roster
forced all 16 PDPs (22 cr). The "index has no prices → budget ≈ one scrape per SKU" rule held exactly.

**6. 9-column Form/Category passed by prefix-luck; lint still can't validate the slugs.** `[lint]` · *later* ·
**confirms Eden's caveat.** 0 `[new?]` forms (all mapped; MDH Drive's "rapid-dissolve tablet" → `sublingual-troche`
was *page-attested* — "dissolves under the tongue"), 1 Form `[?]` (`custom-hair-protocol` is genuinely
multi-mechanism, "oral or topical"), 0 Category `[?]`. A typo'd Form/Category slug would still pass silently — **re-up
Eden's request: add a closed-set check for both columns if the shape graduates.**

**7. Marketing-URL dedup, made easy by the route table.** `[recipe]` · *validate* · **confirms AgelessRx #5.**
Root `/generic-*`, `/glp/lp/v1–3`, `/sermorelin/lp/v1–2`, `/promo`, `/home` are variants of catalogued PDPs. The
bundle's `path:` route list is a clean dedup oracle (real routes vs catch-all).

## The call I'm least sure about

**8. Uniform `partial` for all 16 — defensible, possibly too blunt.** `[contract]`/`[validate]` · **confirms
Hone #6 / Eden #4** (visibility is a stated, brand-shaped judgment) and adds a 4th "why": universal "From $X/mo"
floor, **no membership**, all-in set behind the gated intake. But the GLP-1s *clearly* titrate dose (true moving
floor), while a fixed-dose tablet ("Generic Sildenafil — From $25/mo") may be effectively `published` — the "From"
could be quantity/cadence, not dose. I called all 16 `partial` for consistency + the literal "not self-contained"
test, and flagged it for re-score. **Honest read: this is the one knob a reviewer should second-guess.**

## A tension worth a design decision

**9. The lint grounds price in a captured *page*, forcing a PDP sweep even when the data's already in hand.**
`[lint]` · *later* All 16 prices sat in the JS bundle — but the lint greps `captures/*.md`, not a `.js`, so a
complete priced roster *required* per-PDP capture. Either **persist the bundle as a citable capture artifact**, or
accept the sweep as the cost of grounding. (Mitigated by #4 — the bundle's prices were unreliable anyway, so the
sweep wasn't pure waste.)
