# Developer Review

Question: **What system change does this suggest?**

## Steward

Provenance, freshness, grain, caveats, corpus health.

## Founder

Anti-Doro discipline; avoid machinery and ontology too early.

## Dev Agent

Cheap automation, linting, rendering, templates, or query helpers.

## Triage Submissions

Submit queue candidates only when the review adds new evidence. No-op is acceptable.
Do not graduate, spike, or implement system changes.
