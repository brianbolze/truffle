# Consumer Review

Question: **Where did Truffle create reader value, and where did it fall short?**

Reviewed via the Loop 2 adversarial workflow (consumer pass, Sonnet). Verdict-first.

## Verdict

- **Valuable? Yes** — probably the highest-signal coverage-radar the lab has produced. A
  clean binary result (0 of 5 cross-recurrence head brands captured) with a tight worklist
  and a reframing of the corpus's identity every downstream consumer can use immediately.
- **Why:** the read answers "does a behavioral-health segment exist that we haven't
  captured?" decisively and cheaply. The store-vs-market diff is not thin — it is perfectly
  disjoint. A clean result, not a hedged one.
- **Where Truffle added value:** the corpus-side floor was instant and free — one grep
  (0/54 behavioral anchors) + a token scan over 135 domains, no guesswork. The bounded-live
  panel then proved the gap is real and large, not a narrow-search artifact. The read stayed
  membership-only and distinguished the corpus's **DTC Rx-commerce** shape from the behavioral
  operating model (recurring therapy sessions, insurance billing, therapist matching,
  medication-*management* vs medication-*commerce*). "This store isn't a telehealth corpus,
  it's a DTC Rx-commerce corpus" is reusable insight, not a per-run factoid.
- **Where Truffle added little / fell short:** purely a scope constraint, not a quality miss.
  No size/growth/economics/strategic-interest signal on the behavioral segment. The
  therapy-vs-psychiatry sub-lane (Cerebral/Talkiatry med-management) is under-evidenced
  (SERP/direction-finding grade only); a consumer choosing among Tier-1 candidates gets a
  recurrence-ordered list but no depth signal — appropriate given the contract.
- **What the consumer can do now:** use the tiered worklist directly as input to a
  human-gated `/research-company` campaign (Tier-1 decision-grade; Tier-3 the psychiatry
  starter set), and use the corpus-scope label for any "what does this store cover?" framing.
- **What made it safer than generic Claude + web search:** the store floor is authoritative
  (a real grep over 135 captured domains + 54 telehealth packs, not Claude guessing); the
  insurer-contamination catch (F1) is exactly the quiet error that kills naive coverage-radar
  accuracy; the stop-rule discipline kept spend to 12 net credits with no drift into
  pricing/quality depth.
- **Biggest limit:** 2 affiliate-monetized listicles = coverage radar, not census. Only the
  cross-recurrence head is decision-grade; Tier-2/3 tails are affiliate-confounded. No size
  signal. The in-scope-vs-out-of-scope call is a human one the read explicitly refuses.
- **Human follow-up needed:** (1) decide whether behavioral health is in scope for Truffle
  by design — if not, this is scope *confirmation*, not a gap; (2) if yes, authorize a Tier-1
  capture campaign; (3) sub-lane choice: capture as one behavioral segment, or split therapy
  (BetterHelp/Talkspace/Grow) vs psychiatry-Rx (Cerebral/Brightside/Talkiatry).

would likely be repetitive — the recipe is proven; the next move is capture, not another probe.
