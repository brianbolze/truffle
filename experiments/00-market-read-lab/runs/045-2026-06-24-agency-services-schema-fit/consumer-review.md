# Consumer Review

Question: **Where did Truffle create reader value, and where did it fall short?**

## Verdict

- **Valuable? Yes — buyer-primary.** A marketing/brand leader building a creative-agency
  shortlist is served directly by the prose layer, even though the structured layer fails
  entirely. This continues the run-043/044 shift away from builder-primary value.
- **Why:** all five profiles carry usable capability, specialization, proof/clients, and
  engagement model at a density that supports shortlisting without external research
  (spot-checked: ideo:67-73, redantler:61-64, parlance:62-67). A buyer can rank, filter by
  specialization, and decide on a first call.
- **Where Truffle added value:** the read's split verdict is correct and well-calibrated — it
  lands the buyer value (S1) *and* maps the structural shortfall (G1-G3) honestly, without
  overclaiming "schema fails services." The Parlance partial-transparency capture
  (parlance:64-65) is the cleanest positive demonstration of the price-visibility token
  working as designed.
- **Where Truffle added little / fell short — two modest underclaims against the buyer lens:**
  1. **Budget pre-qualification (CR1).** The Gap Map bundles "rough price" into the
     prose-carries-it-cleanly column, but 4/5 firms give *zero* price signal — only the
     absence of one. A buyer trying to *budget* (not just compare capability) cannot shortlist
     from prose on price for four of the five. (`[on-request]` is the honest answer — but the
     Gap Map conflates capability-shortlisting with budget-qualification.)
  2. **Firm-scale friction (CR2).** Scale is usually the *first* screen a buyer applies (a
     $50K budget self-disqualifies from IDEO; a $500K brief discards solo-operator Parlance),
     yet scale lives only in prose — so the buyer must read all five profiles sequentially
     before the filter can fire. The read calls prose "sufficient for a human shortlist" (true)
     but understates this front-loaded reading cost.
- **What the consumer can do now:** build a real 5-agency shortlist — differentiate IDEO
  (global, enterprise innovation) / Red Antler (DTC + AI-brand) / Bullish (consumer VC+agency
  hybrid) / Heco (complex-product boutique) / Parlance (solo fractional-exec) — and know which
  to call. They cannot pre-filter by budget or scale without reading all five.
- **What made it safer/better than generic Claude + web search:** dated, cited captures with
  honest `unverified_fields` flags (headcount/revenue marked deep-research, not invented) and
  a faithful price-visibility read; a web search would over-confidently invent firm sizes or
  prices that aren't published.
- **Biggest limit:** the cohort is partial by construction (5 captured agencies; market majors
  uncaptured) and the structured layer cannot assemble or filter it — a buyer must already know
  the names.
- **Human follow-up needed:** a first call for budget/scale on 4/5; a SERP/listicle panel to
  find uncaptured majors if completeness matters.

## Lens check

- **Strategist:** lands plainly — the split verdict is a clean, novel read (the entity type
  that most defeats structure is the one prose serves best). Insight is hard to get from a web
  search, which would fabricate firm sizes.
- **The Pantry / downstream system:** a *filtering* system gets little — it cannot select
  agencies by scale/specialization/price from frontmatter (the degeneracy bites here, not for
  a human). Correctly flagged as the boundary in "What Would Change This Answer."
- **First Contact:** yes — the run is honest about what it can't do (partial cohort, no
  structured filter), which builds trust.
