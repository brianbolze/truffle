# Consumer Review

Question: **Where did Truffle create reader value, and where did it fall short?**

## Verdict

- **Valuable? Partly — and the value lands on the builder/Pantry, not the investor.**
- **Why:** The investor's literal question ("who has momentum / is gaining ground") is the
  one Truffle **cannot** answer from static State — and the run's worth is in cleanly
  proving *why* and locating the missing machinery (comparability + a durable time-series
  home), not in producing a momentum ranking. The buyer-facing deliverable is negative
  space ("the store can rank size and stage, but not movement").
- **Where Truffle added value:** A cited, per-company **level** snapshot (capital, orders,
  milestones) the investor would otherwise hand-collate across 8 sites; and the sharp
  diagnosis that *capital ≠ maturity* (cfs is the counterexample) — a genuinely useful
  framing for anyone sizing the cohort.
- **Where Truffle added little or fell short:** No momentum/velocity read at all; the level
  figures are unit-incommensurable (cumulative vs single-round vs absent), so even the
  size ranking is soft; 7/8 figures are self-reported and undated-in-structure.
- **What the consumer can do now:** Build a rough size/stage shortlist and know explicitly
  that "who's accelerating" requires a second capture they don't yet have. They should NOT
  read the capital ranking as a momentum or even a maturity ranking.
- **What made it safer than generic Claude + web search:** The cited level table is warm
  and auditable to dated captures; and the run is honest that the figures are self-reported
  marketing claims (only beta-team is auditable via 10-Q) — a generic web search would more
  readily launder those claims as fact.
- **Biggest limit:** Single capture per company (all 2026-06-14) — structurally no delta.
- **Human follow-up needed:** To get a real momentum read, run `signals/` a second time
  (start with beta-team, the public filer) — spend/approval-gated, out of scope here.

## Lens check

- **Strategist:** Lands plainly. The novel, hard-to-get-elsewhere insight is *capital ≠
  maturity ≠ momentum* — three different axes, only two of which the store carries, neither
  moving. That reframes "how's this startup doing?" usefully.
- **The Pantry / downstream system:** Can consume the per-company level figures as
  ingredients, but **cannot** consume "momentum" as State — it's the run's own Judgment from
  a single snapshot. Same "map-not-ingredient" frontier as run-039/043/047 CR1, now on the
  traction axis.
- **First Contact:** Would trust it — the run is explicit about self-reported grade,
  single-capture limits, and what it deliberately does not claim.
