# Consumer Review

Question: **Where did Truffle create reader value, and where did it fall short?**

## Verdict

- **Valuable? Partly** — and the "value lands on builder, not buyer" pattern holds, with a new twist.
- **Why:** The payload is architectural: the run proves a buyer goal that crosses industry tags is **structurally unqueryable from any field** — a schema-axis mismatch, not a coverage gap. That is a roadmap signal (builder/Pantry), not a buyer's comparison guide. The buyer's "what are my options?" is answerable only by a human reading prose; the assembled set is the agent's Judgment, not a retrievable ingredient.
- **Where Truffle added value:** Per-member State (device price, subscription posture, model structure) is rich and decision-grade for *every* member — if the buyer already knows "Oura vs Whoop," the store serves them well. Honest gap-mapping with receipts (the farm working correctly). The telehealth double-burial (S1) is a real discovery: an Rx sleep line no structured draw would surface.
- **Where Truffle added little / fell short:** The substitute *set* — it is the run's own Judgment, assembled by full-text grep + reader discretion, not queryable State; a downstream system can't consume "sleep/recovery substitute set" as an ingredient. And the read can't certify the set is complete (method-bounded; no external denominator; no CPAP/mattress/app slot).
- **What the consumer can do now:** Use the store as a strong per-brand fact base; treat the cross-industry option map as a hand-built starting point, not a queryable field.
- **Safer/better than generic Claude+web?** Yes for per-member facts (cited, clock-stamped State). No for the option-set assembly — that is reasoning a general agent could do equally, since the store offers no JTBD index to lean on.
- **Biggest limit:** The buyer's question is answerable only by human reading, and the run shows this is structural — not fixable by a field today (JTBD is open-ended/buyer-framed; fails the fillable-cut bar).
- **Human follow-up needed:** The parked bounded-live **C4** ("best sleep tech 2026" coverage radar) to test whether whole solution types (CPAP, sleep apps, mattress brands) are absent — store-only cannot see what it doesn't hold.
