# Consumer Review

Question: **Where did Truffle create reader value, and where did it fall short?**

## Verdict

- **Valuable? Yes** — and unusually, valuable as a *positive*: it shows the store can
  serve a real reader question ("is this deep-tech company real yet?") on an untouched
  vertical, breaking the recent streak where the read fell short for the buyer.
- **Why:** a careful human reader can rank all eight on commercialization maturity from
  store-only State, because the bodies carry dated, specific anchors (first-flight date, IPO
  ticker, binding-order GW, NRC milestone, turbine-delivery year). The honest-absence
  discipline (`unverified_fields`, `[on-request]`, "self-reported") catches exactly the
  over-claims a scout needs flagged.
- **Where Truffle added value:** the cold-start / "is-this-real-yet" read for a
  Strategist or First Contact persona — read the milestones block and you get a workable,
  cited maturity answer with the caveats attached.
- **Where it added little or fell short:** the value is **fully reader-discipline-dependent**.
  The maturity signal is *legible but not queryable* — a buyer who needs to *filter* by
  maturity cannot, and a shallow consumer who quotes `description`/frontmatter leaves with a
  wrong picture. The guard lives deep in the profile.
- **What the consumer can do now:** rank these eight deep-tech cos shipping-vs-vision, with
  citations, for a brief or a cold-start — provided they read the full profiles.
- **What made it safer than generic Claude + web search:** the captured `unverified_fields`
  and "self-reported" labels are pre-attached, so the read does not silently launder
  self-reported funding/orders/pipelines into fact the way an ungrounded web summary would.
- **Biggest limit:** the relay gap — safe if the full profile is read, misfires if only
  `description` or frontmatter is consumed; and the over-claim propagates into the **body
  lead**, not just frontmatter (CR1), so even body-skimming is unsafe.
- **Human follow-up needed:** none required; a 2nd pre-revenue cohort would test whether the
  description-overclaim pattern generalizes.

## Lens check

- **Strategist:** lands plainly — the maturity ranking + "legible not queryable" framing is
  a fast, novel read on a vertical generic search would not caveat as carefully.
- **The Pantry / downstream system:** **cannot** consume maturity as an ingredient — it is
  the run's Judgment derived from prose, not store State. This is the honest ceiling.
- **First Contact:** would trust it — provenance, self-reported labels, and capture clock
  are all visible; the run states its own relay limit.
