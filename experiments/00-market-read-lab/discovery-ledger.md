# Market Read Lab Discovery Ledger

**Status**: Append-only cross-run discovery stream.

## Purpose

Keep raw learning before triage compresses it. This is the notice-and-keep clock:
singletons, misses, wishes, frictions, surprises, source ideas, and gap findings belong
here even when they are not ready for a backlog item.

Triage is downstream. Use `triage.md` only for stewarded build-and-graduate pressure;
keep triage evidence short and link back here or to the run artifact when detail matters.

## Entry Rules

- Append rows; do not merge, dedup, rewrite, or graduate entries in-place.
- One row per sighting. If two runs notice the same shape, add two rows.
- Cite the run path and, when possible, a `run-notes.md` Discovery ledger ID.
- Label observations as observations. Do not turn wishes into fields, tools, recipes,
  or build proposals here.
