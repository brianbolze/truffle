# Candidate Filtering

**Purpose:** packet-local prototype evidence and synthesis for sorting source-discovered entities before they become capture work. This folder is not durable Truffle design.

The coverage packet found that page extraction improves recall, but source domains and marginal actors still need filtering. The work here compares two prototype lanes for that filter.
